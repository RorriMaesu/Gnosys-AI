Local Assistant Setup

Static Hosting Helper

Because Gnosys-AI runs completely inside your browser sandbox, it cannot start local programs directly. To enable AI music generation and local models, please download and run the lightweight assistant helper:

1
Download the helper repository bundle:
Download Helper Bundle (.zip)
2

Extract the downloaded ZIP file to any folder on your PC.

3
Open the folder and double-click: run_backend.bat (Windows) or run_backend.sh (Mac/Linux)
Once running, the helper server registers browser launcher protocols so you can start it with one-click in the future.
